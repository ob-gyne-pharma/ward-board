🔥 Connect Firebase
🧪 Demo mode
1
Create a free Firebase project
Go to console.firebase.google.com → Add project → name it (e.g. "WardBoard") → disable Google Analytics → Create project.
2
Enable Realtime Database
In your project: Build → Realtime Database → Create Database → choose Europe West (GDPR) → start in test mode (you can secure it later).
3
Get your config
Project Settings (gear icon) → Your apps → Add app → Web → register app → copy the firebaseConfig object → paste it below.
Paste the entire object between the { } curly braces. The databaseURL line is essential.
This isolates your ward's data in the database. Choose something unique. Share it with your team.
⚠️ Demo mode stores data in this browser only — not shared with the team. Use this to explore the features before connecting Firebase.
